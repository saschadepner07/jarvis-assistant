JARVIS iPhone-Web-App (PWA)

WICHTIG ZUR INSTALLATION:
Eine iPhone-PWA muss über eine HTTPS-Webadresse geöffnet werden. Diese Dateien allein installieren sich nicht automatisch und ich kann sie nicht direkt auf dein iPhone übertragen oder in deinem Namen hosten.

1. Lade das ZIP herunter und entpacke es.
2. Veröffentliche den Ordner über einen HTTPS-Host (z. B. GitHub Pages oder Netlify).
3. Öffne die HTTPS-Adresse in Safari auf dem iPhone.
4. Tippe Teilen -> Zum Home-Bildschirm -> Hinzufügen.

FUNKTIONEN:
- Offline: Uhrzeit, Datum, Aufgaben, Notizen, einfache Befehle.
- Online-Wissen: ruft bei Internetverbindung Wikipedia-Artikel ab.
- PWA-Cache: Oberfläche wird nach erstem Laden offline verfügbar.

EHRLICHE EINSCHRÄNKUNG:
Der Online-Modus ist eine kostenlose Wissenssuche, keine generative KI wie ChatGPT. Ein kostenloser, dauerhaft garantierter KI-API-Zugang ohne Konto/Schlüssel ist nicht verlässlich verfügbar. Für echte freie KI-Antworten braucht es einen Anbieter mit Free-Tier und meist einen persönlichen Schlüssel; dieser sollte aus Sicherheitsgründen nicht direkt öffentlich in eine Webseite eingebaut werden.
